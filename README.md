# AI Engineer — tutorial labs

Hands-on, graded AI Engineer course labs.

## Setup (once)
```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m ipykernel install --sys-prefix --name ai-engineer
```
Open a notebook and pick the **Python (ai-engineer .venv)** kernel (in VS Code: the `.venv` interpreter).

## How the labs work
Each concept: explanation + SVG diagram → worked demo → **exercise** spec → **🧰 What you need** (every API/idea the
exercise uses, with step-by-step hints) → **🔬 building blocks** (runnable toy examples) → stub cell → **tests** cell →
**🔒 Show solution** button.

| Event | Points |
|---|---|
| Your code passes the tests | **+P** |
| You reveal the solution before passing | **−P** (passing afterwards earns nothing) |
| You reveal after passing | 0 (free, so compare approaches) |

Scores persist in `<course>/.progress/`. Use `lab.scoreboard()` in a notebook, and
`from labkit import course_scoreboard; course_scoreboard()` for a whole course. Reset with
`lab.reset("ex3", confirm=True)` or `lab.reset(confirm=True)`.

## Courses
- `generative-ai-llm-architecture-data-preparation/`: Lab 1 chatbot (115 pts) · Lab 2 tokenization (135 pts) · Lab 3 NLP data loader (120 pts)

## Layout
- `labkit/`: grader, scoring and hidden-solution engine
- `<course>/figures/`: SVG diagrams (generated by `.build/figures_lab_NN.py`)
- `<course>/.solutions/`: encoded solutions (don't decode them, that's cheating yourself 🙂)
- `.build/`: ⚠️ **SPOILERS**. Notebook build scripts include solutions in plain text. `verify.py` runs each
  notebook twice (as shipped: nothing may crash or score; with solutions: everything must pass).
